WAU 개인정보처리방침

이 문서는 모바일 앱 WAU에 적용되는 공개용 개인정보처리방침입니다. WAU는 사용자의 현재 위치 또는 선택한 지역을 기준으로 주변 음식점과 놀거리를 추천하는 앱이며, 기능 제공에 필요한 범위 안에서만 정보를 처리합니다.

시행일 2026-05-31

1. 적용 범위

본 방침은 WAU Android 앱과 관련 웹 정책 페이지에서 처리될 수 있는 정보에 적용됩니다. 앱 기능, 사용 API, 저장 방식이 변경되는 경우 실제 처리 내용에 맞게 본 문서를 업데이트합니다.

2. 처리하는 정보

  • 사용자가 위치 권한을 허용한 경우의 현재 위치 좌표 또는 사용자가 선택한 기준 지역 좌표
  • 장소 검색에 필요한 반경, 정렬 방식, 음식점/놀거리 모드, 검색 카테고리 정보
  • 사용자가 저장한 장소의 이름, 주소, 좌표, 전화번호, 카테고리, Kakao 장소 URL, 저장한 지역명
  • 앱 설정, 최근 검색 지역, 관심/제외 카테고리처럼 사용 편의를 위한 로컬 저장 데이터
  • 이메일 문의 시 사용자가 직접 제공한 이름, 이메일 주소, 문의 내용

WAU는 이름, 계정, 비밀번호, 결제 정보처럼 앱 사용자를 직접 식별하기 위한 계정 정보를 요구하지 않습니다.

3. 정보 이용 목적

  • 현재 위치 또는 선택한 지역 주변의 음식점과 놀거리 검색
  • 거리 기준 추천, 반경 조절, 카테고리 라벨링, 장소 상세 정보 표시
  • 카카오맵 길찾기, 전화 연결, 장소 공유 등 사용자가 선택한 동작 수행
  • 저장한 장소 목록 유지, 앱 설정 유지, 최근 사용 지역 표시
  • 문의 응대, 오류 확인, 서비스 품질 개선

4. 위치 정보 처리

WAU는 주변 장소 추천을 위해 위치 권한을 요청합니다. 사용자가 위치 권한을 허용하면 앱은 현재 위치를 기준으로 음식점과 놀거리를 검색할 수 있습니다. 위치 권한을 허용하지 않더라도 앱에서 제공하는 기본 지역 또는 사용자가 선택한 지역을 기준으로 검색할 수 있습니다.

위치 정보는 백그라운드에서 수집하지 않으며, 앱 사용 중 주변 장소 검색과 길찾기 기능을 위해서만 사용됩니다. WAU는 자체 서버에 사용자의 위치 기록을 저장하지 않습니다.

5. 제3자 서비스

WAU는 장소 검색과 길찾기 기능 제공을 위해 제3자 서비스를 사용할 수 있습니다. 현재 또는 선택 지역의 좌표, 검색 반경, 검색어 또는 카테고리 정보가 장소 검색 요청을 위해 Kakao Local API에 전송될 수 있습니다. 카카오맵에서 보기 또는 길찾기를 선택하면 Kakao Map 앱 또는 모바일 웹으로 이동할 수 있습니다.

  • Kakao Local API
  • Kakao Privacy Policy
  • GitHub Pages

WAU는 현재 광고 SDK나 자체 분석 SDK를 포함하지 않습니다. 향후 광고 또는 분석 기능이 추가되면 본 방침과 Google Play 데이터 보안 정보를 함께 업데이트합니다.

6. 보관 기간 및 삭제

저장한 장소와 앱 설정은 사용자의 기기 내부 저장소에 보관됩니다. 사용자는 앱 안의 삭제 기능을 사용하거나 앱을 삭제하여 로컬 저장 데이터를 제거할 수 있습니다. 이메일 문의 기록은 문의 응대 및 추후 확인이 필요한 범위 안에서만 보관합니다.

7. 정보 제공 및 판매

WAU는 사용자의 개인정보를 판매하지 않습니다. 다만 장소 검색, 지도 이동, 길찾기처럼 사용자가 요청한 기능을 제공하기 위해 필요한 정보가 제3자 서비스에 전송될 수 있습니다. 이 경우 각 제3자 서비스는 자체 개인정보처리방침에 따라 정보를 처리합니다.

8. 아동의 개인정보

WAU는 일반 사용자를 대상으로 하며, 아동으로부터 개인정보를 의도적으로 수집하기 위한 서비스를 설계하지 않았습니다. 관련 법령상 추가 보호가 필요한 정보가 확인되면 지체 없이 삭제 또는 차단 조치를 검토합니다.

9. 정책 변경 및 문의

앱 기능, 사용 API, 저장 방식이 달라질 경우 본 방침을 업데이트하고 시행일을 함께 수정합니다. 개인정보 관련 문의는 아래 이메일로 연락해 주세요.
